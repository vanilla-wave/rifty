Quick start

boot.ts 
import { checkCapabilities, createSandbox } from '@riftydev/sdk'

if (!checkCapabilities().sufficient) return showUnsupportedNotice()

const sandbox = await createSandbox({
  workerUrl: new URL('@riftydev/runtime-js/worker', import.meta.url),
  serviceWorkerUrl: '/sw.js',
})

await sandbox.runtime.eval('console.log("hello from a Worker")')
Cross-origin isolation required

The runtime needs SharedArrayBuffer. Serve with COOP + COEP headers so crossOriginIsolated === true. Header-less static hosts won’t boot it.

also fine on its own:
$ npm i @riftydev/vfs
$ npm i @riftydev/npm-client
$ npm i @riftydev/shell

The leaf packages are plain isomorphic JS — no headers, no worker, runs anywhere.
