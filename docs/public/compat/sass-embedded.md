# Compatibility matrix — sass-embedded

Generated by `pnpm compat:generate` from static inventories backed by conformance and parity tests.

Exact install-only facade claim for `sass-embedded@1.100.0` over `sass@1.100.0`; Final+GREEN is proven against real Node and Chromium.

Legend: ✅ implemented and tested · ⚠️ partial / known caveat · ❌ not implemented (throws `NotImplementedError` or `UNSUPPORTED_PROTOCOL`).

| Feature | Status | Notes |
|---|---|---|

| Direct CommonJS and ESM loading | ✅ | The synthesized facade exposes the measured sass-embedded namespace through require() and import(). |
| Compile and initialized compiler lifecycle | ✅ | The finite oracle pins repeated path/string compilation, sync/async disposal outcomes, exact post-dispose errors, lifecycle export accessors, exported constructor/prototype descriptors, and exact public method name, arity, placement, and identity within and across instances. |

| Legacy render API | ✅ | renderSync output, stats keys, and legacy-js-api deprecation match the exact Node oracle. |
| Vite 7.3.6 SCSS dev, HMR, and build | ✅ | A real nested-partial project proves normalized CSS, edits, maps, warnings, imports, and dependency facts. |

| Direct Compiler and AsyncCompiler construction | ❌ | Exact embedded starts a refed Dart child before rejecting construction; the no-runtime-asset facade cannot reproduce that lifecycle. Throws `NotImplementedError('sass-embedded.compiler-construction-liveness')`. |

| Other versions and version ranges | ❌ | Every request except the literal 1.100.0 is rejected before registry or VFS work. Throws `NotImplementedError('sass-embedded.version')`. |
| Sass CLI/bin | ❌ | The materialized sass bin is a loud gap; the acquired pure-Sass bin never leaks. Throws `NotImplementedError('sass-embedded.cli')`. |
| Watch mode and @parcel/watcher | ❌ | Watch mode is outside the proven facade; @parcel/watcher is never acquired. Throws `NotImplementedError('sass-embedded.watch')`. |
| TypeScript declaration surface | ❌ | No TypeScript declarations or types target are published; exact declaration materialization remains unsupported. |
