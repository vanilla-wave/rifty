## Known Limitations

- Only exact esbuild 0.28.0 and its exact Vite 7.3.6 integration are in this contract; other esbuild versions stay loud gaps, while Vite 8/Rolldown has an observable empty esbuild plan.
- The esbuild CLI is not implemented and throws NotImplementedError('esbuild.cli').
- Every D4 gap must preserve upstream validation and error priority before NotImplementedError; a current early, absent, or silent gate is recorded as partial, never supported.
