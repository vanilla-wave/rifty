## Known Limitations

- No Final+GREEN claim: the upstream-derived runtime, publication slot, common CJS interop/cache correction, and Chromium Vite optimize/build acceptance are still expected RED.
- Only exact esbuild 0.28.0 with exact Vite 7.3.6 is in this contract; other esbuild versions and Vite 8/Rolldown are outside it.
- Every D4 gap must preserve upstream validation and error priority before NotImplementedError; a current early, absent, or silent gate is recorded as partial, never supported.
