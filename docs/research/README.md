# Research notes — provenance, not plans

Snapshots: route or tombstone. On landing (or first reuse) each claim worth
keeping moves to its owner — backlog item, ADR, compat, `docs/process/traps.md` —
and the file gains a `superseded-by:` header line or a row in
`docs/adr/README.md` §Historical references. A snapshot older than its subject
reads as poison: verify against main before citing.
