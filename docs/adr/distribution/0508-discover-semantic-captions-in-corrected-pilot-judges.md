# ADR0508: Discover semantic captions in corrected pilot judges

Status: Accepted
Date: 2026-10-05

## Context

ADR0506 private own-origin checks. Real pilot CSV source/actions rejected for
Paste CSV content / Import CSV / Export filtered CSV; independent HOLDS I6/I3.
Native caption-only working controls RED in both apps. Exact captions are not
public requirements; source IDs/layout remain open.

## Decision

Shared judge-context discovery uses accessible roles/domain word tokens;
descriptions allowed. Fields distinguish primary purposes from mentions of
other fields (CSV header name/email, Search title/body); editable CSV source
separate from readonly output. Navigation entries exclude deletion actions.
Data, workflow and regression assertions unchanged. No source-code scoring.

Exact captions rejected by real alternatives; arbitrary first textbox/button
rejected by functional ambiguity. Role/token discovery retained by explicit
caption/overlap and functional-negative controls; not a universal language parser.

Freeze pilot-v2 with new app case IDs/directories and retained same project,
public prompt/families/control code; originalv1 cases/scores remain history.
New helper bytes enter existing judge-support fingerprint automatically.
Fresh selected72 campaign after controls; no re-scoring prior rows.
