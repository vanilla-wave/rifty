## Decision

Edit/Delete require saved-record identity evidence outside their own caption:
complementary record action in an unambiguous local context, or visible read-only
identity text in a context owning one candidate. Hidden text, editable drafts
and action captions cannot corroborate themselves. Declared domain and existing
control/commit ownership remain. No caption word-order or DOM-shape requirement.

Cancel/Discard word lists are killed by identical opaque-record captions;
mandatory paired Edit/Delete would reject a real unpaired record action.
Both alternatives are covered by actual native carriers. Missing/ambiguous
record context stays an observable error. One shared projection, no state owner,
new dependency, execution coordinator or per-case parser.
