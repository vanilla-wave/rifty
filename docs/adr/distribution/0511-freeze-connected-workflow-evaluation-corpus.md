# ADR0511: Freeze connected workflow evaluation corpus

Status: Accepted
Date: 2026-10-06

## Context

ADR0506 frozen cases/own-origin controls; ADR0507 fixed-matrix inference.
Reviewed pilot72: bounded foreign changes and connected text/CRUD applications;
state/parser/accessibility omissions persist. I1/I6/I7 requires separate expansion.

## Decision

Freeze eval-v1 after controls/review, before model calls: existing6 cases plus
Vue room reservations and Svelte cent settlement.8tasks/7families,6evaluation
families/4appstarters; ms stays calibration. Framework swaps alone insufficient:
new families add interval/capacity and financial conservation/settlement workflows.
Pinned fixture dependencies only; no root runtime dependency/coordinator.

Public prompts own all judged requirements: exclusive half-open rooms, atomic
invalid/reference/capacity guards; safe integer cents, person-creation remainder
order and any balance-clearing transfer algorithm. DOM/layout/control alternatives
open; no undisclosed semantic or appearance requirement.

Retain all reference/setup/functional failures in32-reference matrix and fresh
96quality series, same declared models/100tools/600s/3repeats. Never prune browser
failures or resume old data. Old pilot/input/score history immutable. Existing
loader/runner/report and conditional inference reused; I10/I11 remains separate.

## Alternatives

- Keep pilot only: misses independent domains/expansion I1/I7.
- Expand immediately to20–30cases: original estimate, not quota; actual locked
  inputs/fourcontrols/fourorigins dominate authoring cost. Finite8 justified by
  new invariants; report exact coverage/unknown manual time, no population claim.

Native starter/build/control results and frozen hashes are acceptance evidence,
not assumed support. Protocol: distribution/agent-eval-corpus-expansion.
