# ADR 0519: Resolve workflow operations through observable context

Status: Accepted
Date: 2026-10

Extends ADR0511/0512/0518, overturns none. Existing public action/layout authority;
observed defect repair, no new programme promise.

## Context

Clean eval-v8 completed96 stays immutable/unaccepted. Independent real Vue/
Svelte originals privatePASS; working draft cancellation and contextual Edit Bay/
Edit Train variants publicGREEN/privateRED. Legal room Cancel and cancellation
have identical computed captions but different record contexts; actual edit/
cancel/persistence/reload discriminant GREEN. I3/I6 require trusted observation.

## Decision

One asynchronous workflow-operation projection uses computed accessible
captions and collection/record context. Equivalent Edit/Delete record actions
in their nearest unambiguous context preserve opaque identities. A cancellation
caption without that record context is not an Edit action. Declared domain may
come from accessible collection caption/heading; literal room/expense words in
all row actions are not a public requirement. Existing action-control ownership
and commit equivalence consume this projection. Missing/ambiguous operations
remain observable errors, not first-field/first-record grading shortcuts.

Caption-only Cancel exclusion killed by identical real ARIA names. Making the
subject token optional globally loses domain/record selection. Per-case parser
copies rejected: booking and expense share both action boundary and required
class sweep. No state owner, new dependency, execution coordinator or UI protocol.

## Consequences

Book-v6/expense-v6/eval-v9 retain all five public/control carriers byte-for-byte;
other six cases remain. Shared context changes eight resolved fingerprints;
native-input-v1 unchanged. Original96 source/scores/usage stay history, no rescore.
Real baseline/permanentRED precede implementation; class native/real consumer/
reversion/four-origin proof and independent Final precede new frozen full96.
I10/I11/CLOSE remain mandatory. Initial prototype import/async call-preparation
failures are harness history, never semantic RED.
