## Tokenizer (`packages/shell/src/tokenize.ts`)

- **Unterminated `${` slurps rest of line.** `echo ${X` → the whole tail becomes one literal token, swallowing operators. *Fix:* throw a tokenize error like the `${VAR:-x}` path already does. (med)
- **Unterminated quote silently accepted.** `echo "abc` → completes as a token instead of erroring. *Fix:* throw on EOF inside a quote. (med)
- **`2>&1` / `>&` not modeled.** Lexed as `>` + `&` → the bare-`&` background guard fires (`shell.background`). fd-dup is unsupported; *fix:* recognise `N>&M`/`>&` and throw a clean `shell.fd-dup` NotImplementedError instead of the misleading background error. (med)
- **Quoted assignment treated as env-prefix.** `'FOO=bar' echo hi` runs `echo hi` with `FOO=bar` set; bash treats the quoted word as a command name. *Fix:* the env-prefix popper in `shell.ts:~252` must skip tokens where `t.quoted`. (low)
- **Glob/listing sort is UTF-16, docstring says byte.** `expandGlob` (`shell.ts`), `ls` `byteCompare`, `_walk` sort all `a < b` on code units. Diverges only on astral/surrogate names. *Fix:* compare by UTF-8 bytes or document the limitation. (low)

## Redirect / dispatcher (`packages/shell/src/shell.ts`)

- **`cmd-not-found > f` does not truncate `f`.** The `!handler` branch returns 127 before the redirect-write block. bash truncates the target first. *Fix:* open/truncate the redirect target before the handler lookup. (edge)
- **`echo > a > b` truncates only `b`.** All `>`/`>>` pairs are stripped from argv but only the rightmost target is written; bash truncates every target. *Fix:* write/truncate each redirect target. (edge)

## Coreutils

- **printf:** accepts trailing-garbage numerics (`printf %d 3.9` → 3, no error); `%x`/`%o` of negatives use 32-bit `>>>0` (GNU is 64-bit); missing `\a \b \f \v` (and `\xHH` only in printf, not echo). `packages/shell/src/commands/printf.ts`. (med/low)
- **echo -e** missing `\a \b \f \v \xHH \0NNN`. `echo.ts`. (low)
- **head -c / tail -c** byte-slice then `TextDecoder.decode` → a split multibyte sequence becomes U+FFFD (GNU emits raw bytes). Inherent to string stdout. `head.ts`/`tail.ts`. (med, by-design-ish)
- **cat -A** omits `-v` (show-nonprinting): CR and other control bytes pass through raw. `cat.ts:90`. (low)
- **basename** delegates to VFS `basename` which normalizes first → GNU divergence on `.`/`..`/empty/trailing-dot inputs. `basename.ts:19`. (low)
- **env** ignores all args → `env NAME=val cmd` is a silent no-op (never runs cmd). `env.ts`. Redundant with the dispatcher's own `KEY=val cmd` env-prefix, but the runner form should at least error loudly. (low)
- **head count parse over-permissive** (`-n 0x10`, exponent, surrounding whitespace accepted). `head.ts:28`. (low)
- **grep** no binary-file detection (NUL files line-grepped as UTF-8). `grep.ts`. (low)
- **cd** has no `-`/`OLDPWD`/`PWD` support; `cd -` resolves `-` literally. `cd.ts`. (low)
- **sleep** `setTimeout` 32-bit ms overflow → `sleep 30d` fires immediately. `sleep.ts:34`. (low)
- **head error wording** prints "No such file or directory" for every non-EISDIR read error, masking ENOTDIR/etc. `head.ts:151`. (low)

## Terminal (`packages/terminal/src/`)

- **replaceBuffer / handleBackspace desync** for wide (CJK) chars, tabs, and multi-line paste: one `\b \b` per JS char assumes 1 cell/char. `terminal.ts:172/218`. Needs wcwidth-aware erase. (med, cosmetic)
- **history index stale** on Ctrl+C / blank Enter → next ArrowUp skips the most-recent entry. `terminal.ts:159`. (low)
- **keys** strips only CSI (`ESC [`); SS3 (`ESC O …`) and `ESC`-letter sequences leak their tail into the buffer; C1 control bytes (0x80–0x9f, incl. 8-bit CSI 0x9b) pass through. `keys.ts:95/110`. (low)
- **No Ctrl+D (EOF) handling.** (low)

## VFS (`packages/vfs/src/`)

- **OPFS `renameSync` loses empty subdirectories on disk.** In-memory index re-keys them, but `persistRenameAsync` only recreates files → empty dirs vanish on next `refreshIndex`/reload. `opfs-sync.ts:~724`. (med, browser-only)
- **OPFS `copyFileSync` writes empty bytes on a cold cache.** `this.content.get(s) ?? new Uint8Array()` → copying a file whose content isn't cached (e.g. right after reload, before any read) silently produces an empty copy. `opfs-sync.ts:628`. Verify the cache lifecycle, then read-through on miss. (med, browser-only — data loss if real)

## Architecture / cleanup

- **Extract a shared `parseFlags` helper.** 9 commands hand-roll the optsEnded/`--`/bundled-short-flag/NotImplementedError preamble in 3 slightly-varying shapes. `_shared.ts` is the home. The variance is the hazard. (low)
- **Parity gold-standard cases** for the new behaviors: `cp`-into-self EINVAL, `mv FILE dir/` into-dir, `rm -fr`/dir-without-r — add to `tools/node-parity-runner/cases/` (ADR-0086 prefers parity over hand-written assertions). (low)
- **e2e for the rich-terminal wiring.** The `isTTY/cols/rows/signal` + `onSignal`→`interrupt()` path now resurrected in the playground has unit coverage (adapter/terminal) but no e2e asserting columns/color/Ctrl+C in a real browser terminal. (low)
