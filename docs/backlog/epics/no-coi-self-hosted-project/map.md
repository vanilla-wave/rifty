# No-COI self-hosted project — map

## Items

1. `distribution/no-coi-worker-startup` — I1/I2: configure authoritative boot
   storage and effective startup budget; prove native namespace/default/fallback,
   delayed ready, timeout and close. Same configuration survives restart.
2. `distribution/no-coi-self-hosted-project-open` — I3–I6, after step 1: first
   remove saved-install admission from ordinary open while retaining point-of-use
   adapter validation; then compose explicit snapshot application and force.
   Packed Vite cold apply/edit/reload/update/interruption closes the whole goal.

Both children stay draft until PICKUP/Contract+RED. One delivery group/PR by
default; no mandatory split per issue. Existing worker operation, VFS and snapshot
validation owners carry shared behavior; no new coordination mechanism prescribed.
